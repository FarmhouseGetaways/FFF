Construction

Built on a 120×120 grid, matching ivizhin's own mark exactly so the two frames are identical — only the centre glyph and accent colour tell them apart.

  • Frame: four corner brackets, arm length 24 units, corner radius 8, stroke 5, round caps and joins.
  • Uptick: M30 84 L56 74 L88 30 — a shallow opening run (30,84 → 56,74) bending into a sharp rise (56,74 → 88,30). Stroke 6, round caps and joins.
  • Arrowhead: M74 37 L88 30 L85 45 — an open chevron computed to the actual angle of the final leg, not a guessed 45°.
  • Clear space: a quarter of the mark's width, all four sides.

Type

Wordmark "Farmgirl Finance" is set in Fredoka Bold (700), the same face every heading in the app uses, colour #2c4c2c on light grounds and #eef3ea on dark, tracking −0.01em.

Rules

  • Never rotate the mark, and never recolour the accent beyond the values above.
  • Never place the mark on a saturated or busy fill — grounds stay cream, white, dark green, or single-colour print.
  • The frame is shared with ivizhin on purpose. Don't redraw it independently if either mark changes later — update both from the same brackets.
